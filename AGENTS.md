# Global agent instructions

Apply the `clear-writing` skill to all prose output by default. This covers replies, documentation, commit messages, pull-request text, release notes, error messages, and code comments. It does not apply to code, identifiers, or command syntax.

Skip the skill only when asked to write freely, or when the task needs marketing or creative copy.

Load the skill with the `skill` tool before you write the text. The skill lives at `~/.config/opencode/skills/clear-writing/SKILL.md`.
